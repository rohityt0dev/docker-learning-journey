# Docker Logs

`docker logs` is used to **view the logs generated by a Docker container**.

Logs are useful for monitoring applications and troubleshooting errors.

## Basic Syntax

```bash
docker logs [OPTIONS] CONTAINER
```

Example:

```bash
docker logs my-nginx
```

## Create a Container

```bash
docker run -d --name my-nginx nginx
```

View its logs:

```bash
docker logs my-nginx
```

## Follow Logs

Use `-f` to continuously watch new log output:

```bash
docker logs -f my-nginx
```

Press:

```text
Ctrl + C
```

to stop following the logs.


## Useful Log Combinations

### Last 50 Lines

```bash
docker logs --tail 50 my-nginx
```


## Check Container Status

Before checking logs:

```bash
docker ps
```

To include stopped containers:

```bash
docker ps -a
```

Then:

```bash
docker logs my-nginx
```

## Troubleshooting Example

Run a container:

```bash
docker run -d --name web-server nginx
```

Check status:

```bash
docker ps
```

Check logs:

```bash
docker logs web-server
```

Follow the logs:

```bash
docker logs -f web-server
```

If the container has stopped, check:

```bash
docker ps -a
```

Then inspect the logs:

```bash
docker logs web-server
```

## Common Options

| Option | Purpose |
|---|---|
| `-f` | Follow log output |


## `docker logs` vs `docker exec`

| Command | Purpose |
|---|---|
| `docker logs` | View container output |
| `docker exec` | Run a command inside a container |

Example:

```bash
docker logs my-nginx
```

```bash
docker exec my-nginx ls
```

### Key Point

> **`docker logs` helps you monitor and troubleshoot a container by viewing the output generated by its main process.**
